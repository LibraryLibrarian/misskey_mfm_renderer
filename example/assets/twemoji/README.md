The full license is in [`LICENSE-GRAPHICS`](LICENSE-GRAPHICS).

Source: [jdecked/twemoji v17.0.3](https://github.com/jdecked/twemoji/tree/b6b55fef1e8636b540a6d016a4729ca8cdf2e60b),
commit `b6b55fef1e8636b540a6d016a4729ca8cdf2e60b`, directory `assets/72x72/`.
All eight 72×72 PNGs are **unmodified**, preserved byte-for-byte. Source URLs,
SHA-256 hashes and sizes are recorded in [`source-manifest.json`](source-manifest.json).

The subset contains 😀, ❤️, 1️⃣, 🏳️‍🌈, 👍🏽, 🇯🇵, 👩‍⚕️ and the England tag flag.
It is not the full emoji set and does not imply full Unicode 17 parser support.
The catalog's explicit filename allowlist falls back to Unicode for other input.

Upstream code is MIT-licensed; its [`LICENSE`](LICENSE) is retained for reference.
No upstream source code is copied into the helper. The package's own license
must not be interpreted as replacing the separate graphics license.

When reusing these graphics in an application or documentation, retain suitable
attribution to Twitter and contributors, link to the source and CC-BY 4.0, and
state whether you modified the graphics. `MfmTwemojiBuilder` itself does not
supply attribution UI or download these assets for an application.
